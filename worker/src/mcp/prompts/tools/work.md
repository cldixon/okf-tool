Beyond files: what needs doing in this library: open comment threads (requests from people; a thread with no path is on the library itself), requests (`request`: threads marked as a bigger ask, left for people's agents to do, then reply and resolve), stale pages (past stale_after), broken links (body links and `sources` resources in this library that point nowhere; checked on every write and again daily, so a move or delete elsewhere shows here), lint (dangling footnotes included), hotlinked images (`external_image`, one item per page: `attach` each with `source_url`, `edit` the image to the attached path, cite the original in `sources`), and structure (what makes a directory's index.md poor: descriptions missing, too long or repeating the title, duplicate titles, pages nothing links to, directories with one page, none or too many; reported on the page or on the directory's index.md, and never fixed for you), ranked by how many pages link in. Each item has a suggested action; fix it through the normal write tools, and answer comments with `comment`. `kind: "stale_soon"` looks ahead instead: pages within 14 days of stale_after, to refresh before they go stale; only moving stale_after resets the clock.
