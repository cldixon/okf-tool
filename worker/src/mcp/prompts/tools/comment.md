Beyond files: answer a comment thread or start one. `reply` adds to a thread; `resolve` closes it (with an optional closing reply, e.g. what you changed); `reopen` opens it again; `open` starts a thread on a page, optionally on a `quote` copied from its body as `read` shows it (matched by the text it reads as, markup aside; it must occur once; quote more of the sentence if it repeats), or with no `path` on the library itself. `kind: "request"` with `open` or `reply` marks the thread a request, a bigger ask left open for people's agents (`work` lists it as a `request`); `kind: "comment"` makes it a plain thread again. Resolve only what you actually addressed. Write `@handle` in a body to address someone who can reach the library: it reaches their inbox. Comments never change the page; edit it with the write tools.
